Diagnostics

Every fault in one pass.

A fail-fast validator stops at the first problem, so fixing a document takes one round trip per error. TSON collects all of them, each with a code, a path, what was expected and what was found. Edit either pane — the schema compiles and the document validates entirely in your browser, with no network involved.
